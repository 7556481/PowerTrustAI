# EIA/NRC待复核回答与预期草案v1

2026-10-21，接续本人题卡复核及“下一步”指令，为[两题](reviewer-eia-nrc-question-cards-v1.md)各制作4份待复核回答。共8回答、16个coverage要求槽、12个参考语义单元。**全部为AI标注建议，尚未本人确认，不是预测或执行冻结。**

样例包括中文同义合并表达、遗漏/部分表达、明确错误关系或整体否定、无据附加。不是给每题机械套相同完整/遗漏/保证三种模板，也不把8个变体当成8个独立来源。两题仍在原两个来源关联组内；本轮未新增来源、改题或调整通用提示/解析器。

完整回答、逐槽coverage建议及逐单元支持参考只留忽略目录`data/evaluation_local/holdout-source-selection-v2/answer-drafts-v1/`：

- candidates/answers.draft.json：仅题号、候选ID与回答，不带预期或变体角色。
- evaluator-only/review-table.md：供本人阅读的8项逐项复核表。
- evaluator-only/expected-labels.draft.json：coverage v2及支持预期、理由、程序计算的原文位置，禁止进入模型消息。
- manifest.json：绑定两张修订题卡SHA及上述文件身份；是助手工程记录，不记为本人核验。

本轮没有模型输入拼装或付费入口。预期使用covered/partially_covered/missing/uncertain及原生支持枚举，不从旧met/not_met自动转换，也不引入not_supported的未审定义映射。

## 复核重点

请分别检查：反向区间关系是否明确涉及所问方面；把求和定义改为平均是否为定义关系错误；NRC只说核转变、未表达时间是否partial；整体否定原定义是否仍覆盖所问方面。上述均为待复核语义判断，不能从已有开发题结果自动推定答案；有歧义先hold，必须在预测前解决。

NRC完整定义回答不需要主动否定危害消失；若另加危害断言，支持性独立判断，不据原子比例或常识自动判事实矛盾。EIA系统数量与区间要求独立，避免错误运算影响区间覆盖。模型未来可拆分/合并命题，参考语义单元不强制等于程序句子载体；一条载体含两要求时不能机械漏判。

## 状态与下一步

回答/参考原文区间及ID对应、题卡证据身份、manifest和固定协议源码SHA核对通过；旧文件不覆盖。工程核查不是语义验收，亦不证明来源完全独立或模型训练未见。文本复核不自动扩展为JSON/SHA确认。

先由本人逐项复核回答、coverage与支持预期，歧义项hold；之后才固定参考单元匹配、请求顺序、实际覆盖报告、调用/纠正和停止计划，并取得具体载荷授权。不因新样例特点调整固定通用协议；若必须调整，相关材料转开发并重划来源。**本轮0模型调用，不提交私有回答/证据/预期全文，不制作ZIP。** 本地短报告提交后普通推送。
