## 页面修改

默认不勾选“记住本机连接”。用户主动选择且受保护运行列表鉴权成功后，保存当前origin的本机token；网页刷新自动恢复并重新验证。只存version/token，不读取或保存DeepSeek密钥，不放URL/日志/归档。localStorage按协议/host/port隔离，不跨8765/8768或localhost/127.0.0.1替换不同服务令牌。

取消勾选会删除当前origin保存项，当前页仍以已连接内存使用；“忘记连接”清除当前页内存/输入及当前origin保存项，停止轮询/禁用需鉴权操作。其他已开同源页已有内存不被远程撤销，刷新后不能从删除的保存项恢复；这不是服务器令牌轮换。用户可在仍连接页按自己选择重新勾选。

所有受保护请求401统一清理失效连接/保存项/偏好，要求本机核对固定文件再手动连接，绝不自动重发POST。网络不可用不等于401，不因此删除已有记忆。过期异步响应不能清掉后来连接，忘记期间旧连接请求也不恢复状态。浏览器拒绝保存时退回内存；拒绝删除时明确提示手动清除此地址站点数据，不伪称清除成功。

本机存储未加密，同浏览器配置使用者和同origin脚本可访问；只在用户明确选择后保存，适合本人可信电脑。原Bearer/local-only/同源/CSP/SSL保护保留。backend/api仅把新增同源JS加入静态白名单，不放开任意文件。代码入口backend/static/connection_memory.js、app.js、index.html/style.css；backend/local_access.py固定复用机制保持。
