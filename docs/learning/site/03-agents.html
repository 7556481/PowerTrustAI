03 四Agent与ClaimExtractor：对象比角色名称重要

Generation：生成不是审核

GenerationInput包含问题、工程上下文、实际交付Evidence、绑定、知识版本及回答要求。agents/generation.py约束模型跟随用户语言、直接答题、保留必要条件和引用单元。程序保存生成输入快照并绑定answer_id/version。模型输出存在字数或JSON问题时，有限纠正要求重写完整合法内容，不用字符串截断删技术限制。

无成功检索依据时的程序中文说明不是实质回答。Harness标记no_substantive_answer后，提取和双审不适用，终止待补充；不能对“当前未找到依据”模板做昂贵全文事实审核。如果转换查询连接失败则是执行失败，而非证明模型不懂中文。

ClaimExtractor：冻结错误，不替它改正

提取器是服务，不是额外审核Agent。输入冻结答案，输出主张、组件、立场、限定、义务及non_claim覆盖。程序根据实际锚点计算原文区间，拒绝漏覆盖。proposition是规范表达，不能把“四类”顺手改“三类”，也不能把“可能”改成必然。

混合句应按组件理解：一句既说技术值又说“材料未提供X”，分别需要technical_content与input_snapshot等依据。冻结组件分类后，审核可以提出真实异议，但不能为了supported把technical_truth偷换成“答案写了这句话”。提取忠实性与事实真值分开：准确提取的错误回答应能得到contradicted或insufficient。

Evidence Verification：两项独立义务

独立核验检查当前知识快照是否有支持命题的依据；原引用审核检查答案当初引用的那段资料能否支持对应正文。独立找到正确证据不能治好原错误引用。正文、元数据、输入快照、答案原文和计算结果用不同typed basis，来源适用性登记不能冒充官方技术正文。

模型承担支持关系、必要条件、因果方向及真实异议。程序只证明ID、版本、范围、字面存在和派生处置一致。旧接口曾让模型重复生成quote_ids、basis_indexes、conditions_preserved等字段，结构复杂性导致纠正负担；合法结构仍会有原引用语义误判。

Domain Review：问工程前提，不装作仿真

领域审核收到同一答案/主张及工程背景，检查范围、输入、前提、量纲及仿真边界。概念转述不无条件要求厂站模型；设定值和性能保证必须保留相应输入义务。演示规则有版本和适用范围，不是国家标准库，也不执行潮流。模型high标签或话题高风险不能机械等同于高风险回答。

Revision：执行有界修复，不授予通过权

Revision读当前发现及经过验证的修复依据，输出新版本和处理摘要。可定位、有已交付原文支持的普通缺陷有一次修复机会；真正缺资料、缺工程输入或执行失败不能靠删掉问题变“解决”。其他未解决项继续保留。完成后重新提取、重新调用两审核，再由政策处置。

回答原文: 在C下A导致B。
忠实提取: 在C下A导致B。         → 原对象可核验
错误提取: A总是导致B。          → 提取异议，不能直接通过
证据原文: 在C下A导致D。         → 支持问题，不单独说明提取不忠实

以上是教学构造；C是否真的必要、A与D是什么技术对象仍需要语义判断，程序不能通过字符串相等证明全部技术含义。

为什么不能投票定真伪

事实与领域审核不是三个独立测量仪。相同基座、提示与资料会有相关误差；多个模型重复同一偏差不会变事实证据。Domain“未发现工程问题”不能抵消Fact的缺证据；NLI supported不能抬高原结论。应按不同义务组织发现，不按多数票平均。

同样，Severity、Support和Fidelity不是同一变量。Severity描述影响，Support描述依据关系，Fidelity描述提取对象是否忠实。一个错误计数可以contradicted但普通严重度；一个厂站保证没有依据可以insufficient但影响需另判；一条事实正确却被提取变味的句子仍须保留异议。

验证、坑与面试练习

离线回归要涵盖“忠实提取错误答案”“不忠实提取正确答案”“忠实正确目标”三种组合，而非只测supported。模型语义评测另看真实原文与标注来源。默认关闭NLI时应无加载/推理，开启也不进入Agent或Revision消息。

练习：解释为什么“答案说输入已给出”不能靠answer_text_reference证明输入真实存在。参考：该basis证明答案原文说了X，input_snapshot_reference才证明实际交付中存在X；两者都不证明X工程上真实。

面试可说：“四角色是职责隔离，ClaimExtractor生成冻结审核对象。最终处置用确定性政策汇总必须义务，我没有用多数票当真值。模型可合法提出提取异议，程序保留原始与有效判断。”
