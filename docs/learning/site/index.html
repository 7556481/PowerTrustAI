PowerTrustAI 学习入口

从产品里的一个审核意见出发，沿一次请求读到代码，再练习解释能力与边界。运行配置只看当前状态；本书的旧代码与实验按绑定版本阅读。

先选一条路线

  • 第一次了解产品：读完能解释用户会拿到什么，以及“给出意见”和“修改正文”有什么区别。
  • 沿一次请求读源码：读完能追踪检索、生成、双审、修订与版本保存，指出每一步能验证什么。
  • 准备面试：读完能用证据讲清技术取舍与失败边界，再完成从产品到代码的实操。

最终交付系统优先路线

能力—正文—代码—练习索引：先读24→25→26→27，再读31修订授权、35并行时间线与37正式协议。Dense/RRF、NLI和训练保留历史/进阶，不作为首读前置。其他技术见邻接基础。

正文与历史怎样分开

前20章先读最终机制与基础推导，带日期/候选补记转入逐字归档；每章末可展开旧标题定位。面试只从第17章当前入口开始。历史快照是旧记录，不是当前配置；32—34章分别练控制变量、产品等待和恢复状态。

归档案例路线
