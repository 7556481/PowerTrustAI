PowerTrustAI：从代码到判断的学习路线

这是一份给项目所有者的中文工程教材，不是运行报告合集。你只需要会Python的函数、类、字典、异常和基本文件操作。学习目标是能沿一条真实请求解释：哪些文本送进模型，哪些关系由程序验证，模型错了会发生什么，为什么某个分数提高仍不能自动采纳。

正文唯一来源是 chapters 下的Markdown。页面是这些文件的静态派生物；改Markdown后运行构建器，搜索和导航一起更新。无需文档云、账号、付费API或新的训练环境。右侧是本章目录，左侧是全书目录，上方可搜索中文术语、函数名和公式。双击项目根目录 start-learning.cmd 打开8770学习服务，不会重启8765日常审核服务，也不读取其令牌或数据库。也可以直接打开 site/index.html 离线阅读，搜索无需fetch。

先建立四个判断层次

程序成功返回JSON，只说明协议可解析；完整执行表示必需步骤完成；supported是给定对象与实际证据之间的模型判断；pass是政策对当前任务的处置。四者不能互换。程序能证明原文区间和ID一致，不能因此证明原文正确、命题被支持或厂站安全。

本书每个公式算例标为“教学构造”，不会伪装成实验结果。真实实验有独立版本、样本数量和分母；监督来源写作AI辅助、用户监督。生产行为依据正文标记的代码版本，历史描述保留当时含义。原始响应、全文库、数据库、凭据和权重不进入本学习站。

三条阅读路线

  • 第一次理解产品：01→02→03→04→08→09→10，先读用户问题如何变成审核对象。
  • 算法与实验：05→06→07→11→12→13，亲手计算BM25、RRF、混淆矩阵，再看为何实验没有改变默认配置。
  • 面试与排障：14→15→16→17→18，拿着代码追一条请求，练习回答“失败在哪里、凭什么这样判断”。

每章都包含概念、工程取舍、代码入口、验证方法、坑和面试说法。不要一次记住所有协议版本；先理解对象，再理解它为什么需要版本。

阅读时应持续核对的当前边界

当前日常采用固定部分快照、BM25/FTS倒排及aggregate交付，本地NLI默认关闭且没有决策权。可选Dense/RRF存在，历史reranker实验未采用。项目执行有限标量换算，没有潮流、短路或动态稳定仿真。全文语料仍由独立唯一写者构建，不自动替换日常库。真实自动修订在早期配置中曾发生；最新原功率因数验收没有触发，不能说所有后续配置均已验收。

本轮站点先绑定6108030源码。之后审核简化和12题批次将在第08、15、16章更新为实际结果，不提前写成功。代码摘录与版本清单由构建核对记录保存；“待核对”只用于没有证据的内容，不作为空章节的替代。

如何和ChatGPT继续完善

请将具体章节Markdown及 questions-for-chatgpt.md 一起提供。优先补项目所有者当时的决策动机、替代方案和面试表达；新增事实必须给代码、原始报告或明确标为个人反思。不要把模型生成的解释升级成实验真值。可以加练习和推导，不能改写历史失败。

正文章节完整保留两本旧手册的合理基础内容，但用当前源码重新核对：旧版“未微调”“schema12当前”“没有中文页面”等只能作为历史。没有把旧PDF转换成网页就称正式完成。
