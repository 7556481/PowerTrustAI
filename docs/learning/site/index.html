先建立四个判断层次

程序成功返回JSON，只说明协议可解析；完整执行表示必需步骤完成；supported是给定对象与实际证据之间的模型判断；pass是政策对当前任务的处置。四者不能互换。程序能证明原文区间和ID一致，不能因此证明原文正确、命题被支持或厂站安全。

本书每个公式算例标为“教学构造”，不会伪装成实验结果。真实实验有独立版本、样本数量和分母；监督来源写作AI辅助、用户监督。生产行为依据正文标记的代码版本，历史描述保留当时含义。原始响应、全文库、数据库、凭据和权重不进入本学习站。
