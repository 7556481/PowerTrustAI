# 证据绑定评审组件小规模基线规格v1

2026-10-21。规格ID：`reviewer-component-baseline-spec-v1`。本人已确认本规格的能力边界、规模与报告方式；AI整理归档，非专家金标准。取代[门槛草案](reviewer-validation-gates-draft-v1.md)作为下一阶段准备依据，原草案保留为历史，95%、90%、理由充分比例及无法对齐必须为0均不采用。本规格不是最终批次执行冻结或付费授权，不另加一轮门槛草案。

## 目标与固定候选

评测给定问题、要求、题设、证据、待评回答的评审组件，建立“有限来源隔离的组件表现与后续回归基线”。不测整条RAG，不改默认检索、生产协议、四Agent/Harness或审核政策，不迁移LangGraph。

采用当前已冻结v7提示`explicit-rationale-layout-eval-v7-dev`＋v6严格解析`addressedness-claim-target-eval-v6-dev`；v7.parse必须仍与v6.parse为同一函数。模型选择合法单元/依据ID，程序计算位置及composition；不补理由、不替换ID、不放宽校验、不叠提示。[机器规格](reviewer-component-baseline-spec-v1.json)绑定当前源码与提示SHA。旧[通用候选v1](reviewer-independent-protocol-candidate-v1.md)绑定v5，保留原身份；本规格继承其映射、对齐、有限纠正和停止边界，显式以v7/v6组合替代候选身份，不覆盖旧冻结。

覆盖仅评明确回应：明确说反仍可covered，实际缺必要内容/范围/条件才partial/missing。支持性独立：缺证据不自动矛盾；文献定义不虚构现场核验；题设假定不当作现场已核实；真实实例断言保留实际记录依据要求。理由和正确依据ID都不自动证明支持成立。

## 固定工作量与覆盖规划

**4个新来源谱系组、8个问题家族、24份回答**。操作分配为每来源组2个问题家族、每家族3份回答；同家族及同组结果相关，不能将24回答或更多语义单元称为独立统计样本。本规模是工作量规划，不是统计充分性证明。

支持、矛盾、证据不足三类均纳入参考设计；同义表达、遗漏、条件边界、题设应用均需在预测前覆盖清单中有明确落点，允许一个回答同时涉及多种现象。不要求每个家族机械各凑一个支持类别，不为配额制造歧义。`not_assessable`仅在有清楚适用案例且参考确认时纳入，否则明确记未验证。文献/假定/应用/实际对象的类型边界逐项保留，不声称本批覆盖所有能力。

CT/TR/SW/RC、MIT/BIPM、EIA/NRC及同文档、转载、翻译、近重复谱系均属开发，不能回保留集。新来源需记录版本、定位、快照身份及有限谱系审计；来源隔离不证明基础模型训练未见。先筛来源、确认选段，再制作问题/要求/回答/参考；本人确认标签后才最终冻结执行。歧义项预测前hold、保留原因；若无法按固定规格填满规划，不自行减规模、替换口径或改提示，报告缺口。

## 有效性要求与成绩分开

|层面|固定处理|
|---|---|
|实验有效性|参考标签、参考理由、人工切分和质量预期不进入模型消息；身份、版本及原文绑定正确；原记录不改；失败全部交代。违规明确说明受影响范围及相关结论无效，不将其混记模型语义错误|
|执行|首次字段完整按预期要求/单元ID存在唯一无遗漏、无外来替代，不依赖数组顺序；契约有效另评非空理由、合法字段/枚举/ID。分别报首次和最终有效实际分子分母、纠正、失败、未执行，不设百分比准入线|
|覆盖与支持|分别报覆盖混淆、支持混淆、错误支持、错误拒支持、关键边界错误，不合成总分。没有必要条件不能由理由补进回答；必要限制不能推出充分保证|
|类型与对齐|按事前冻结类型及语义匹配逐项复核；等价拆合可联合映射，参考只计一次。混合标签/部分等价不挑有利从句；冲突及额外预测另列。无法对齐降低可评价覆盖，不自动判模型判断错，也不要求无法对齐为0|
|理由|逐要求、单元、判断记录空泛、标签冲突、无据推论及边界遗漏；整体总结不替代局部。理由非空不是充分性评分，不设主观95%门槛；公开摘要与预测理由原文、本人文本复核与本地SHA核验分清|

统计单位在最终批次清单明确：要求为覆盖统计单位；支持统计以冻结参考语义单元为单位，程序载体数不是分母。对最终有效且无冲突、可按冻结规则对齐的参考单元形成可评价集合E；等价拆合后每参考仅计一次，合并预测映射多参考须披露并非多次独立判断。

- F：E内参考为insufficient_evidence/contradicted/not_assessable、预测为supported的参考单元数。
- A_NS：E内上述非支持参考单元总数；A_SP：E内预测supported的参考单元总数。分别报告F/A_NS、F/A_SP，零分母N/A。额外预测、冲突、未对齐、失败及未执行不混入E，全部单列，并同时报告E占计划参考单元的可评价覆盖。
- 错误拒支持：E内参考supported而预测任一非支持标签的数量，分标签列出，报告其占E内supported参考的比例；零分母N/A。
- 覆盖混淆以最终有效响应中可对应的原要求为单位；其余要求状态单列。支持混淆限E，不能据此把未对齐部分视为正确或错误。关键边界错误逐案列影响，不反推修改参考。

参考标签如需转换，须预测前核对原定义与定位/SHA并确认；not_supported只有明确表示缺支持且矛盾另列才映射insufficient_evidence，混含或歧义不猜测。unknown不当不相关，不删除以改善成绩。

## 一次冻结、一次执行、完整报告

本轮只固定规格和工作量。来源筛选后，最终批次在预测前一次绑定：4组谱系、8家族、24回答、所有要求/前提/证据/参考及映射、人工确认范围、代码/模型消息SHA、24请求完整顺序及选序方法、配置与执行入口、停止规则、原始归档目录及attempt锁。数据/实际响应/输出留Git忽略data，不公开官方全文，不制作ZIP。

运行配置沿既有候选：deepseek-flash/API目的地api.deepseek.com，单请求90秒、最多2000输出token、24000响应字符、90000消息字符；提供商默认采样及漂移未知。实际配置必须在执行冻结核实，不因超限临时改提示或截断任务。24初始，每项最多一次格式纠正，共享最多48调用、4320秒预算准入期限（非硬墙钟保证）；首执行/传输/存储/最终契约失败停止，其余未执行。无传输重试、Revision、自动恢复、换目录补跑或按语义追加纠正。复用现有控制器，不另建调度器。执行仍须新的具体载荷/费用授权，旧批授权不沿用。

报告全部计划、尝试、首次/最终有效、纠正、失败、未执行、未对齐、冲突及其来源/家族/类别覆盖；初始与纠正token、已知实际费用分别列。完成前缀不代表整批，失败停止不靠补跑凑齐24。

出现错误支持或关键越界，明确记相应能力未达预期；没有观察到也不证明总体可靠、生产准入或工程安全。缺明确案例的能力记未验证。若结果用于改协议，该材料转后续开发，原冻结成绩和失败保留；本批不追求调到全对。

完成本批并经限定范围复核后，才能把冻结任务和统计作为后续回归基线。LangGraph迁移需另立任务，使用同一套冻结评测比较退步；已见回归材料不再包装成新独立验证成绩。迁移本身不解决模型误判。
