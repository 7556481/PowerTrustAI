## 环境与启动

Windows，本项目解释器为 `D:\PowerTrustAI\.venv\Scripts\python.exe`。已有环境无需重建。仅缺少 API 依赖时安装锁定依赖：

```powershell
cd D:\PowerTrustAI
& .\.venv\Scripts\python.exe -m pip install -r requirements-api.lock.txt
& .\.venv\Scripts\python.exe -m backend --demo --port 8765
```

页面：[http://127.0.0.1:8765/](http://127.0.0.1:8765/)。只运行一个服务进程；终端 Ctrl+C 停止。端口占用时先确认已有服务，勿启动第二个操作同一运行库的进程。可指定其他 `--port`，浏览器地址同步修改。仅监听 loopback，不部署公网。

演示模式 `synthetic_fixture` 使用现有假组件，不加载 `.env`、不请求真实模型或知识索引，页面明显标识。真实模式使用原 Harness、默认 BM25、固定知识快照、事实审核 schema12、领域规则和有限修订政策：

```powershell
# 日常真实模式，会产生模型费用；冻结实验另行记录计划
& .\.venv\Scripts\python.exe -m backend --port 8765
```

启动与健康查询不调用模型；真实提交会付费。日常使用由用户主动提交，默认服务模型调用上限40，不要求每次编写实验授权和冻结计划；对照/验收实验批次才独立冻结输入、配置、上限及停止条件，若实验授权少于40须相应控制。环境变量优先，真实入口通过既有加载器读取项目根 `.env`；密钥配置见 `.env.example` 的字段说明，勿复制实际密钥到聊天、截图或运行材料。

## 令牌与密钥

本机访问令牌控制浏览器访问本机 API，与 DeepSeek 密钥完全不同。首次服务启动生成随机令牌，重启复用 `data/runtime_local/access-token`。用户只在本机查看：

```powershell
notepad.exe D:\PowerTrustAI\data\runtime_local\access-token
```

将其填入页面“本机访问令牌”，不加 Bearer，点击连接。页面清空输入框，授权值仅在页面内存，刷新需重填；不写 URL、localStorage 或日志。DeepSeek 密钥始终在服务端，不交给浏览器。不要截图凭据文件或填写中的令牌。

## 操作流程

1. 先确认页面当前服务模式；历史记录保留各自 real/synthetic_fixture，不能混同。
2. 选择问答或已有回答审核，输入问题；后者须提供原回答。背景、回答要求和用户参考可选，参考来源保持未核实。本界面不构造工程参数。
3. 提交一次后立即保留 run_id，通过状态和阶段事件查看。结束后停止轮询；可输入 run_id 或运行列表恢复。无虚构进度百分比。
4. 结果分别显示运行终态、必需阶段完整性、必需检查是否评估和业务结论。阶段完成但无法评估可以同时成立。中文摘要区分执行问题、证据不足、矛盾和工程前提；原始原因及 JSON 保留在详情。
5. 原回答、当前回答、保存版本、逐轮发现和修订动作分别查看。事实模型、领域模型、程序规则和工具分开；部分 supported 不表示整体可信，pass 不是工程安全认证。
6. Evidence 回查检查原文、来源、文件页、字符区间和质量告警。原引用与独立检索依据分开；提取文本未核对 PDF 视觉原文。合法公开 HTTPS 来源可打开，禁止不合适协议、凭据 URL 与本机来源路径；没有来源时显示“未提供”。链接不含本机令牌，服务端不自动抓取 URL；本轮未验证外部网站当前全文可达性。
7. 选择实际回答版本和可选 finding，追加确认、反对、待查或说明。意见保留来源，不覆盖模型判断，AI辅助用户监督不等于专家金标准。

## 错误、取消与重启

401：重新输入本机令牌；409：刷新后选择实际版本/finding；429：队列满，等待后手动提交；422：检查必填和长度；503：检查服务或配置，不自动换演示组件。网络错误显示状态未知，不能解释为任务不存在。不会自动重新 POST；重复点击锁定。请求是否接收未知时先查询运行列表，再决定人工重试。

取消先显示已请求，实际终态以服务为准；远程请求或线程不保证立即终止。未完成运行可查看已保存有效部分结果。反馈保存失败保留输入；不确认成功时先回查，避免重复意见。

同一 SQLite 继续保存运行和反馈。重启将未完成任务置 interrupted，不自动重发；完成记录和追加意见保留。仅一个活动运行、两个等待位置。浏览器通过 API 访问，不能解析数据库或读取运行文件。
