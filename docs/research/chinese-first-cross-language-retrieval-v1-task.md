## 3. 一个默认关闭候选：来源范围与正文查询分工

复用现有Retriever/Evidence、GenerationQueryConverter、Factory/Harness及Store，新增独立版本的检索profile与manifest，原默认不变。不新建Agent或编排器。

### 3.1 来源解析

来源约束只来自用户问题实际出现的文献标题/机构及既有目录可证别名。标题精确对应则限定该文献；仅提机构则保留该机构所有匹配文献；多个同名/版本有歧义不擅选。指定来源不存在，返回明确未找到所指资料及可检查目录信息，不静默用行业正文冒充。未提来源，沿原中文大库路径，不额外调用模型。

不能硬编码NERC、题号、目标source_id/页码、8题关键词或问题→段落表。来源机构需元数据验证，正文出现机构名字不等于该机构出版。未知元数据不能猜补。目录匹配规则对其他机构同样适用。

### 3.2 跨语言查询

当解析出明确来源范围且范围内存在英文正文、问题为中文时，在本profile内执行一次现有Flash英文查询转换，不再以第一次检索是否为空作为前提。仅把原问题作为待转换数据，不给参考答案、目标段、必答点、旧审核发现或模型生成的预期结论。

优先保留现有GenerationQueryConverter的单query合同和max_corrections=0、忠实转换要求；如需机械接线保留model_records/usage，允许修复，但本轮不扩成多个查询生成器，不增加查询纠正次数或模型选文献。转换失败明确记录，本次候选槽失败，不把悄悄回退后的旧结果算跨语言成功。

英文查询仍是检索表达，不是事实依据；不能强制答案采用其中技术表述。记录保留原问题中否定、数字/单位、N-1/N-2及必要限定的情况，人工来源优先评价其忠实性，不把英文格式合法等同转换正确。

### 3.3 文献范围内召回与交付

在已解析范围内分别用原查询和转换查询做词法召回，来源字段不作为正文必须包含的词；不再用“首名词/输出形式”作本路径硬subject。使用通用分词/停用词处理，不为已知题补词典；公式、缩写、数值不得随意丢弃。

两路各取固定最多20候选，按固定RRF(k=60)合并去重，稳定ID打破并列；最终仍top-k=3，邻接2400字符/6片段、深度1、跨页及storage_order沿历史设置。不得调融合参数/扩大上下文来追分。所有命中保持真实fragment/source/version和来源角色，查询计划与结果可回查。

允许复用基础小库现有词法检索或对小目录建立可重建的轻量词法派生索引，必须纳入既有Retriever接口/确定性验证，不复制发布大库或改不可变FTS。不超过基础目录已有12文献、总片段上限10000，派生数据上限100MB；超限报告而非自动扩大。实际如直接读现有索引更简单则不另建。候选只在文献范围内运行，不能为省时偷偷退化成给定参考四段。

## 4. 固定三路检索，分清改善来源

付费前固定原N1—N8不改题/参考；另固定4个反例：未指定来源的中文行业问题、同一机构内多文献存在歧义、指定文献不存在、主题相近但属于另一真实机构。用现有目录/材料，明确反例参考，不能把参考塞进路由器。所有材料已见开发性质如实披露，不称独立保留集。

每题最终只跑一次三路检索：

- A：当前生产原检索profile，当前知识版本，真实运行并核对历史差异。
- B：与候选相同来源解析/文献范围/通用分词/去subject，但只使用原问题，不发转换请求；单路top3，作为范围与查询规则变化的对照。
- C：完整候选，在B的相同范围基础上加入英文查询召回与固定融合。

未触发来源/语言条件时B/C沿各自设计的相同无转换路径，记录而不强行补调用；A/B/C范围不同时明确披露，不能把C相对A的所有差异都归为翻译。B与C才用于判断跨语言查询的额外作用。

记录来源参与/候选/实际交付、必答证据槽覆盖、错误来源归属、丢失的有用证据、字符/片段数及延迟。片段命中不等于覆盖正确；另一同机构文献若真正回答必答内容，应按事前参考规则评价，不能只数唯一目标source_id。

候选业务与评分规则在任何付费转换前冻结。离线用人工小型通用中英fixture完成接线测试即可，不拿人工答案查询伪装实测改善，不对真实题付费试提示。12题三路最终运行不反复调参，语义失败也保留。

## 6. 回答阶段启动条件与评价

在冻结结果上评价后，仅当以下全部满足才自主继续：C相对A至少4/8题、跨至少3家族实际必答证据交付提高；不丢失其他题A已交付的关键证据；4反例无新增错误来源归属/擅选版本；8题C无执行失败。达不到就结束本批，不能重新翻译/调规则后再评。

另单列C相对B增益。如果只有B改善而C不增益，明确没有证明额外模型调用值得；即使总门槛达到可以完成已授权回答比较，但不能推荐所有请求默认加转换。

回答对照使用A/C冻结实际交付，8题各新生成两路；同一原问题、同一现有生成提示/模型参数/预算。顺序按题交替A先/C先，固定Evidence回放保留真实来源及生成快照。不能给C提供更多预算、参考答案或额外资料，不能用旧自然答案代替本次A。其范围是检索输出后的生成对照，不是整个产品在线端到端性能。

独立复核先看来源与问题，再看遮蔽分支的两路正文，最后看系统记录。AI辅助/用户监督、非专家金标准，披露盲化范围。逐题公开完整答案、必答点正确覆盖、关键错误/遗漏/无据扩张、引用归属、改善/相当/恶化/混合/执行不可评价。检索到原文但没有正确作答不算收益。
