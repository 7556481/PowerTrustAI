## 已证实、推测与未知

**已证实：本次检索记录累计耗时较大。** 4检索记录合计137.742秒，与后台计数器的比值约90.8%，不是测得的关键路径占比。后续[离线诊断](retrieval-performance-diagnosis-v1.md)确认事件还有嵌套，不应直接求和；原缺单调起止区间不能补称精确贡献。代码和轨迹顺序：两次生成检索→生成→提取→事实检索→领域检索→并行双审的较慢事实分支→政策/收尾。137.742+2.115+1.796+max(9.288,3.618)=150.941秒仅为计数器近似分解，约0.7秒未归类，不能全称持久化。模型请求资源时间14.705秒含并行重叠，不当关键路径；每次3核心命中不代表12个独立/去重来源。

推测：当前MATCH+BM25排序、宽泛OR/固定领域词可能扩大排名工作，顺序检索使两个较慢阶段累积。当前计时不能证明排序、正文读取、邻接和验证各占多少，不把137.742秒改称FTS时间；未发现任务中重新全库SHA的证据。

未知：准确单调排队、查询准备、FTS执行/取回/排序合计、正文读取、结果验证、持久化及首次答案commit、浏览器首绘、供应商内部排队、命中规模和本次查询计划。未额外运行昂贵MATCH、全库计数或用EXPLAIN估算秒数。已有duration_ms是单调计时、毫秒截断；UTC事件只用于近似对齐。外部首次发现含1秒轮询误差，起点还包括提交HTTP。冷热OS缓存未控制，不与不同历史题作严格A/B，也不称普遍耗时。
