# 从启动到结束

在项目根目录、既有虚拟环境中操作。当前稳定候选尚未完成发布，状态见[验收报告](maintenance/stable-product-baseline-v1.md)。

1. 公开离线演示运行 `./start-powertrustai.cmd --demo`。打开 http://127.0.0.1:8766/fixture/connect ，确认“演示模式 · 无模型调用”。此入口不加载私有知识库与凭据。
2. 填入概念示例，生成并审核，检查答案、正文意见、引用依据、历史及版本。合成结果只说明交互，不证明模型能力。关闭终端前用Ctrl+C正常退出。
3. 真实服务运行 `./start-powertrustai.cmd`。需要原固定知识库、已有受管配置与Flash凭据。配置缺失应处理终端错误，不能改用演示充当真实结果。
4. 首次启动等待固定知识封印；不要重复启动多个服务或把封印耗时当每题检索耗时。健康状态未知时不重复提交问题。
5. 正常使用先阅读初稿，等待审核结束，再看证据、不足和可能的修订。绿标不等于回答正确或工程安全。
6. 停止前确认任务已结束、队列为空；运行 `.\.venv\Scripts\python.exe -m backend --stop --port 8765`。无法确认在途请求时不强杀、不重放。
7. 真实固定批次必须独立冻结并使用现有预算/usage入口；本轮固定十题已执行一次并封存，禁止重跑；见[结果](evaluation/stable-product-baseline-v1/report.md)。不能以日常提交替代冻结验收。
