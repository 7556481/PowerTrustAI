## 职责与协议差异

保留全部理由字段：要求级解释明确回应了什么；判断级解释证据与命题的支持关系；单元级解释判断是否覆盖该原始单元的实质断言、边界及拆分不确定；总理由仅作简短总览。单元理由承担独立职责，不能删掉后以判断数、总理由或程序拼接冒充。

v7仅调整提示组织：移去v6中间的旧结构示例，以程序维护的OUTPUT_SHAPE在末尾给出唯一示例，并将unit.rationale列在judgments之前；明确单单元/单判断也必须给出该同级字段。JSON键顺序只是提示布局，不成为拒绝条件。所有内容、标签枚举、必要字段和验收口径不变；parse、输入白名单和依据角色校验直接复用v6，无补理由、改ID、默认字段或宽松解析。没有新增程序派生理由，也不规定每句只能含一个判断。

既有一次结构纠正、精确路径诊断、预算和首最终失败停止保持。诊断可能显示被复用的v5/v6校验阶段，未来实际请求协议版本须显式采用v7；本轮没有新付费入口或最终批次冻结。
