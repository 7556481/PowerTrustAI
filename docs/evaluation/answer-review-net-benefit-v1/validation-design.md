# 固定真实验证设计（预测前）

材料正文留Git忽略目录，公开[题目、独立必答点、允许表达与来源定位](materials-reference.json)；冻结后不换题。本轮材料经AI辅助设计/来源阅读、用户监督授权，均登记开发验证，不是专家金标准或独立留出。复用已归档NERC Reactive Power Planning Guideline（2016）动态/静态资源与故障分析选段；不下载或扩库。四份固定回答为本轮构造，不是自然生成或真实工程记录。没有注入发现、分类或强制Revision；目标缺陷自然未出现时不补题。

A四组成对各一次（8分支）：动态资源错误；相近正确静态回答；静态解释有据而匿名容量缺输入；动态/静态颠倒并依赖错误类型作稳定保证。顺序逐组原/候、候/原交替。同组问题、初稿、原引用和实际证据固定，只切revision_answer_delivery。默认审核/政策自主判断是否Revision；正确回答未修订照实保留。

B四题仅各生成一次（4个G），使用当前生产生成器与默认BM25/aggregate/topic_v4_subject_v1、lossless_v1、固定完整知识版本。每题两路从同一实际初稿与完整交付快照开始（8个B），不重生。A/B配对审核固定证据，不再补检，避免后续检索改变比较来源；这只是在评价Harness上的固定证据接缝，生产检索配置没有变化。故本轮结论限于固定交付的审核修订，不冒称新生产问答批次端到端净收益。B保留自然初稿至最终的实际变化；下游提取/审核随机性保留，单次成对差异不能归因于提示。

参考仅供评价，不进入模型消息；代码只将questions/drafts/evidence构造成请求，发送前另查评价键。实际消息发送前独立落盘哈希；未来响应依赖的纠正消息不能预造。源码、材料、参数和20槽顺序冻结；实际发送与原始无效尝试全保留。

预算不是8或20次模型调用。A无补检时每分支初始为提取1+事实独立I+领域1+原引用C（本材料C=1，I由实际对象决定）；修订若触发还需Revision1+新提取1+新独立I2+新引用C2+新领域1，并遵循原有限纠正。B先记录实际生成g_i（含可能转换/纠正），两个分支独立使用40-g_i余量和800秒减实际生成耗时，不共享可变ModelBudget或判断；不为每节点新加额度。每A保留原40硬帽/800秒、一次Revision、请求90秒/步骤110秒、零瞬时重试；全成功生成下总硬上界为8×40+Σ[g_i+2×(40-g_i)]=640-Σg_i，实际调用按发送与记录核对，不追求耗尽帽。

净收益逐题人工辅助阅读：对照预定必答点、初稿和最终正文，分别记正确纠错、正确内容误改/删失、漏修、新错、必答补齐/丢失、合理收窄/不必要拒答、阻止认可但未修成、正文不变合理核验/错误降级。原始支持、有效支持、程序处置分开；结构合法不算内容正确。采用要求：有完整任务收益且无关键新增错/必答点丢失的实证，否则保留候选或不采用；四题不估计通用准确率。

执行统一复用run_fixed、ComponentFactory、OfflineHarness共享阶段、RunStore和saved_result。单例最终MODEL_OUTPUT_ERROR保留并继续；外联/配置/身份/存储/未知程序问题停止后续发送，受理不重发，响应保存失败也停。SQLite在所属事件循环创建/使用/关闭，独立收集器另开只读连接显式关闭，Windows释放已离线演练。没有候选常驻服务，无生产切换；结束核对生产原状态。
