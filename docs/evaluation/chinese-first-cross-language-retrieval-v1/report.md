## 中文主线的依据及边界

发布manifest中有73个已处理分区：chinese路径19个、english路径54个；处理的输入行分别7,373,300与6,962,877，另有3个英文分区因已核验的Parquet不可读被排除。发布去重记录8,630,479、片段24,620,273，**没有按语言拆开的去重后正文统计**。分区名/处理行不是精确出版语言比例，不能按分区数量说英文占多数，也不能宣称大库几乎全中文。沿既有导入统计完成核对，未遍历70GB或追加代表性不足的全库抽样。

基础目录12份、674片段，全部目录身份已核对；纯脚本文字规则为3中文、3英文、6混合，混合常含中文资料中的公式/缩写，不能当作出版语言认证。按既有保守英文body判据，NERC两份和PNNL一份实际有英文片段，其余9份不触发该判据。机构、标题、版本、别名、正文脚本、哈希及未知信息见目录；没有从标题/机构猜补工程权威。

因此保留用户的中文提问/回答主线，同时保存英文原文；只在明确目录来源范围含英文body时转换。这个选择符合当前中文使用场景，并非根据全库精确语言优势得出。没有来源的中文问题仍走原路径，未全面解决开放跨语言搜索。

## 为什么不继续回答

N6原问是接入后的输出与日常投入退出；实际译文为：

> … post-connection output characteristics and commissioning/decommissioning operations …

这把运行中的投切比较换成调试投运/停用退役程序。其余输出/额定电压维度保留，不能抵消换义。8条JSON和模型请求都合法，程序完成与语义忠实必须分开：**8条结构有效，7条忠实，N6实质失败**。

第一位来源复核者曾初评为措辞风险，细读原问及原段后修正为实质错误；另一位在不知道召回和门槛结果的新上下文中也判断实质不忠实。主执行保留初评与修正，采用严格事前规则。N1 Operators对应原题“运营方”，没有因为参考术语差异另外造翻译失败。

有效C>A数量/跨家族条件和反例保护虽满足，但任务明确规定转换不忠实使C槽失败，而启动回答要求八题C无失败。故gate=false，唯一批次结束。16回答槽为**条件未触发**，不是16个生成失败；不重译、不修代码续跑、不花剩余额度探针。没有成对新答案，改善/相当/恶化/混合均未评分，回答收益尚未证明。旧H3审核漏检、N4“大设备”、固定初审修订4/4及自然v3旧结论保持。
