## 失败原因与语义疑点

事实独立初始响应存在两类契约错误：第3项semantic_review内非法嵌套classification_issue；第4项“该规则并不强制省略标记M”选正文、未选提取阶段登记的题设。一次纠正清除了非法字段，第4项仍仅选正文，触发 `definitive premise/application needs all explicitly selected premises`，整项拒绝并保留有效同伴。其后仍完成当前分支原引用审核；最终失败归档后才停止后续分支，符合分支级停止规则。

这里不能只说模型“忘记联合依据”：提取器将非强制规则本身也列成scenario_application，并登记83题设。但原文明确“无论评分如何……均不要求必须省略”，该陈述可视为文献规则本身，单正文足以支持。严格校验正确执行了冻结类型约束，却暴露了**对象分类与所需依据之间的语义疑点**。不事后改分类、放宽门禁或将无效supported计入成绩。原响应的非强制判断有文本理由，并不因此成为有效审核结果。

保留的题设转述使用独立task_premise_reference；阈值比较、省略许可、保留许可使用题设＋正文；范围声明使用answer_text_reference。没有将生成快照用于替代技术正文。原引用supported只代表其冻结作用域判断，不能单独证明83来自文献或整个应用结论已完成独立审核。理由中“达标是允许省略的必要前提”在本题明确低分禁止的封闭规则下有据；不能推广为任意规则的必要性。
