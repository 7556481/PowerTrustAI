HTTP错误只读取有界8KiB、内存中解析后丢弃原文，不保存请求头/凭据/原始错误。记录有限HTTP状态、白名单错误类型、按状态给出的安全错误说明、本地关联ID；安全形状的服务端关联ID仅存哈希。原始message可能回显输入/密钥，统一省略并明确diagnostic_gap，不把安全说明冒充服务端逐字错误。信息不够就保留缺口。ModelCallRecord沿已有network_diagnostic可选字段保存，旧记录兼容。

simple_v1提示v9.22.1及投影v1.1不改。程序提供来源整片段和裁剪后的答案锚点ID/原文/位置/版本/作用域；模型不重抄关系文本。条件存在、答案表达、实例信息分别判断：none/not_applicable可与instance missing共存而派生不足；无条件不豁免合法来源。原始S不能盖过来源/条件/实例缺口或异议；unknown保持不确定，执行占位不是模型语义无法评估。72个声明组合与既有投影表离线核对，合法来源类型、ID和引用作用域门禁保留。
