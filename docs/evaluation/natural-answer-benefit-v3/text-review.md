# 独立文本复核与揭盲

两位只读子Agent只看各自私有packet：先来源/事前参考，再评X/Y；未展示先后、answer_id/版本、执行状态或系统理由。顺序用交替调换而非随机；主执行不是盲评，不称正式双盲。两位均未编辑、加载.env、联网或发项目模型请求。揭盲后再比较系统，来源为AI辅助、用户监督，非专家金标准。

N八题正文增量均相当，原题完整收益因目标资料未交付均不可评价。这是两个轴：不能把相当说成正确，也不能用资料不足抹掉能观察到的未变化。N4有实际资料可修的关键限定错误，仍漏修。H正文均相当，但H1审核失败后终局记不可评价；H3关键排他错误漏检。

| 例 | 正文/交付终局 | 实际资料与冻结参考评价 | 保留风险 |
|---|---|---|---|
| N1 | 相当/相当 | 实际交付是组织/工控安全资料；建模方式和两类位置均未答。 | 缺目标文献，不是与冻结正文矛盾。 |
| N2 | 相当/相当 | 交付的一般无功备用/监视协调不能补齐边界LPF、双向支撑和关键负荷协调。 | “须协调”略强但不计新的关键强制义务错误。 |
| N3 | 相当/相当 | 未交付事故分析原段，立即/无干预/紧急限值、稳态稳定及最小最大负荷均缺。 | “作为支撑条件”概括有弱依据；未明称必要/充分，仅次要疑点。 |
| N4 | 相当/相当 | 正常/N-1有部分资料，选定N-2及极端扰动目标原段仍缺；“单一大设备”无据缩窄原交付的“单一设备”。 | 核心故障范围错误，可据实际交付资料删“大”修复；初末均未修。 |
| N5 | 相当/相当 | 非NERC行业语料的一般补偿器说明有据，但不替代指定带宽、自动实时连续与两种模式定义。 | 不把源文中的同步调相机说法额外升级为专家确认的工程真值；原题仍未完成。 |
| N6 | 相当/相当 | 投退/额定容量有部分资料，未给NERC动态静态分类、平方依赖、手动自动投切及额定电压含义。 | 没有将静止补偿器直接混同NERC静态资源；元数据只说明出处。 |
| N7 | 相当/相当 | 只交付图形/文字符号资料，未交付短线路式及变量定义；未答原题。 | 没有凭空填式子、符号或数值，是资料不足。 |
| N8 | 相当/相当 | 只提供一般无功/电压损失关联，未提供所问模型边界、三驱动强弱及双向紧密耦合。 | 源文“R,XI”残缺，参数条件表述保留提取/语义疑点，不计关键反转或因果强化。 |
| H1 | 相当/不可评价（执行失败） | 主要技术含义有据；未逐字写“实时”但快速响应语境可接受，无关键错误。 | 揭盲后执行失败：事实审核两次额外type，不能算正确稿审核保护成功。 |
| H2 | 相当/相当 | 建模/LPF/协调及元数据适用性总体有据，无关键正文错误。 | 自愿性/非中国标准来自applicability，非第37页技术正文；整体Evidence支持不等于原引用正文支持。 |
| H3 | 相当/相当 | “选定N-2仅用于确定稳定极限”是关键排他扩大；when不推出only，实际来源已交付，可修而未修。 | 该段“无干预”绑定N-1不等于其他标准下N-2允许人工干预。 |
| H4 | 相当/相当 | 短线路/忽略R/B/公式变量与强弱方向均有据，范围保留，未见关键错误。 | 不做数值计算及不外推正确，具体参数缺口不阻碍文献概念解释。 |

具体来源身份/范围、N4及H3短引证、机会数与遮蔽方法见[text-review.json](text-review.json)。完整初末全文及所有引用见[cases.json](cases.json)和[cases.md](cases.md)。

H2复核分层：独立评者认可适用性声明有元数据依据；主执行保留系统将原引用正文与元数据支持混用的既有疑点。未把它改标关键编造，也不把system pass当引用支持正确的证据。H3独立评者与系统有明确分歧，报告采来源可复核的when/only差异，未事后改参考。
