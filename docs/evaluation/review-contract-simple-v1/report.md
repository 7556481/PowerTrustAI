## 实际实现与回退

新显式fact_review_contract=simple_v1（环境POWERTRUST_FACT_REVIEW_CONTRACT=simple_v1），提示evidence-verification-v9.22-simple-v1／合同fact-review-simple-v1。只允许当前schema13/原事实Agent；默认production即回退。旧scope_v2、schema14、联合/两阶段均保持旧行为，不采用。复用ReviewCatalog合法typed依据、CandidateScope整片段、答案anchors、scoped_fact_execution及Factory/外层LangGraph/Store/API；不复制Agent、Harness或控制器。

原文单元复用whole_fragment，保留原文本、片段内偏移、父片段/来源版本/定位和scope_binding；答案单元按既有段落anchor与当前表述区间相交绑定，保留版本与正文SHA。来源SRC:与答案ANS: ID隔离；同一来源可供多个目标分别判断。整片段/段落只是定位辅助，不宣称原子语义真值；未规范化字节、切语义或制造新原文。

模型每行九字段：status,basis_ids,reason,gap_answer_ids,conditions,inference,objection,repair,requires_authoritative_source，身份由有序位置绑定。conditions仅一份六字段对象：applicability(none/present/unknown)、expression(not_applicable/preserved/missing/misattached/extended/uncertain)、instance(not_claimed/satisfied/missing/uncertain)、source_ids、answer_ids、reason。三维和理由必须显式声明，空ID数组不自动表示无条件或无遗漏。数值/术语来源仍通过依据及理由说明，不自动变成适用条件。允许未找到条件，不凑来源。

精确摘录和位置均由程序提供，模型不重抄source_subject等六段。只输出新修订建议文字时允许replacement自由生成；它不充当事实依据，必须来源绑定并完整重审。初始、示例、纠正统一同一字段表；不存在关键词自动改标签、补依据或消除异议。

投影simple-condition-projection-v1复用typed依据/authority/异议/repair校验，明确绕开旧条件投影：none/not_applicable/not_claimed不因无条件引入遗漏；present下遗漏/错挂/扩大或实例信息不足阻止raw supported；unknown/归属不确定保留复核。三维声明互相冲突、或声称保留却缺当地绑定时明确记录projection_reasons并保留不确定。原始支持与结构声明冲突单列，不能靠raw supported覆盖缺口。合法语义无法评估与执行占位仍分开。

三种范围保持：完整性按事前必答点人工辅助复核；事实看实际完整命题；原引用只看绑定表述与原引用。问题/邻文仅消歧，不新增全题裁判，不跨单元补条件或扩大引用。
