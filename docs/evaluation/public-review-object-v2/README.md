## 合法异议与字段位置

已核实旧提示已有classification_issue同级示例，但它只接受不同category；literature与scenario_application同属technical_fact，所以该字段不能表达此处的同类别争议。不能把它嵌入semantic_review，也不能建议相同category。

本候选复用既有同类别提取忠实性异议通路：semantic_review.fidelity为disputed或uncertain，理由明确原对象、建议对象、实际原句以及题设为何不相关/为何必需，status为not_assessable。只选冻结类型允许的依据，无兼容依据可为空。程序保留原分类、异议与依据，派生review_required，不静默改分类，不准入答案。它是提取对象争议，不是证据不足，也不是现场事实有误。没有新增JSON字段或降低校验；真正应用的supported/contradicted仍必须正文＋所选题设。若未来要将对象争议拆为独立结构化字段，应另立版本，本轮未做。

例（教学合成）：`达到50分允许P`是规则；`本题55分，因此允许P`是应用；`无论评分多少均非强制`是规则。若最后一句被误登记应用，审核可明确异议而不补选55分。此时进入复核，并不把该项自动改成合法supported。
