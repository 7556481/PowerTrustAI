# 固定回答原版／候选对照计划

本材料完整准备、尚未付费执行。全部是明确合成的开发题，参考为AI辅助建议、用户监督，不是专家金标准。参考不进入模型消息。实际回答、声明题设、正文、组件及工具输入（空）均由fixed_input唯一构造，双方相同，不重跑生成／提取、不用新检索。两版不伪造已有回答的生成快照。

|案例|参考与理由|
|---|---|
|F01 图书馆|规则复述只依赖正文；当前19岁符合18岁门槛的应用依赖正文＋年龄，不依赖蓝卡。两项supported，不把许可写为义务。|
|F02 样本|8度不满足不高于4度必要条件，“符合且允许”的完整结论contradicted。|
|F03 课程|24≥20成立，只需学分与正文；背包颜色、学生编号无关。|
|F04 分数|71来自题设、64来自正文，71>64；须同时保留两个来源。只比较数值，不证明工程资格。|
|F05 档案|字面是规则复述，却预置为input_evidence_coverage；期望保留raw支持和独立分类异议，effective not_assessable，不静默改类型。原版缺快照预条件不算异议检出。|
|F06 承载|正文没有900kg数据，insufficient_evidence；不因同主题而支持。|
|F07 记录|12忠实转述题设supported，21错误转述contradicted；这判断“题设说了什么”，不是现实记录真值。原版无生成快照能力缺口单列。|
|F08 寿命|电流不能据此推出50年，缺寿命模型及其他条件；insufficient_evidence，保留没有工程计算工具的限制。|

顺序：F01原→候选，F02候选→原，依次交替至F08。具体16分支清单及实际首消息SHA见preparation-v1.json。模型deepseek-flash；90秒请求、8000输出token、96000响应字符；沿用40调用分支保护、不自动重试；本批每有模型请求的分支只计划1初始＋最多1纠正。当前原版F05/F07由程序缺快照门禁不发送：总14初始，条件纠正≤14，最大28调用；这两个零调用分支算“未完成全部必需检查／原版能力缺口”，不能算首契约成功或成本优势。其他路径均无原引用；原引用隔离另由离线回归覆盖，不伪造引用生成历史。

分支时间上限800秒、步骤110秒，原既有预算保护；真实执行前必须绑定入口并核对调用计划、每次发送前消息和完整来源SHA、写入不可恢复attempt。参考标签不可用于构造模型消息。当前只有只读／捕获准备入口，没有可意外付费的execute命令。

停止：首次最终结构／执行／存储失败立即停止后续分支，保存当前合法同伴、原始失败、计数和未执行名单；不重发、不换目录恢复、不补跑求通过。语义contradicted／合理不足／有效分类异议是有效观察，不因非pass而停止。已知原版程序预条件是事先登记的能力差异，保留并继续对照，不作为意外执行故障。若计数或归属、输入身份发生变化，0新增发送并停止。

统计分开：

- 首次契约有效：首次响应完整通过契约的分支／实际初始模型响应；同时给16计划分支中的分母，零调用和未执行单列。
- 最终执行完整：必需目标都有有效模型判断，且无执行问题；已知预条件、占位不能混入完整数。
- 支持判断：逐组件raw/effective status及参考对照；错误支持、正确矛盾、合理不足分别计，不只报pass比例。
- 异议处理：F05预置故障单列，fidelity与classification分列；不算自然分类准确率。其他意外异议逐项审阅。
- 实际依赖：是否包含必要来源、是否选无关题设、数值两个来源是否保留，列完整分母；未知保留，不视为不相关。
- 调用：初始／纠正／未发送，按本次invocation和answer version；领域／生成／提取为0。
- token：输入／输出／缓存／总计，缺返回记unknown；费用不把估算当账单。
- 耗时：分支端到端单调时间、模型每请求时间、准备时间分别计，不叫首绘。

必要理由复核逐行格式：case、variant、answer_version、target_id、初始/纠正、raw_status、effective_status、object_kind、classification_objection、fidelity、选中依赖原文与ID、比较操作数来源、条件保留、完整reason原文、结构错误、合法同伴、执行状态、calls、tokens、seconds。无效响应理由原文另列，不从无效契约提取“成功语义成绩”。用户统一复核整批，不拆小确认。
