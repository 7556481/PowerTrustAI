## 实现与开关

- [OfflineHarness](../../../harness/runtime.py)新增仅开发构造参数`execution_path="langgraph_v1"`，默认`"sequential"`。`run/cancel`签名及结果类型不变；现有生产工厂、API及数据库代码均未改。
- [共享运行上下文](../../../harness/execution.py)保留原顺序驱动`run_stages()`，在同一`run(driver=...)`边界内只运行所选驱动。原Agent、Extractor、Retriever、严格解析、政策、预算、observer、失败和取消处理复用。
- [图运行时](../../../harness/graph_runtime_v1.py)的7节点分别调用7共享阶段，条件边决定问答/已有回答、早期终止、政策终态及Revision回到完整提取/双审。双审继续在一个节点内并行，未重写合并机制。
- 不调用完整旧驱动作为单节点；测试把旧驱动改为抛错，图仍完成预期阶段序列和修订回环。
- 图不配置RetryPolicy、节点结果缓存、checkpointer或store，不暴露resume。显式关闭框架云追踪；在外层开启追踪且禁止网络连接的替身测试中仍通过。
- 图的递归上界按修订预算派生，只是编排防护。业务调用预算/截止时间仍由原运行上下文和ModelBudget管理，格式纠正仍只由原`structured_request`处理。

开发选择示例：

```python
from agents.fakes import make_fake_harness

harness = make_fake_harness()        # 默认 sequential
harness.execution_path = "langgraph_v1"
# 使用既有 run(request, budget, ...)；这里没有供应商或真实模型。
```

直接构造也可传`OfflineHarness(..., execution_path="langgraph_v1")`。未知路径、依赖缺失或关键版本不符在Agent执行前拒绝，不隐式选回旧驱动。Backend没有新环境变量或UI开关来启用图。

## 依赖兼容与锁

[可选依赖入口](../../../requirements-langgraph.txt)及[完整锁](../../../requirements-langgraph.lock.txt)针对本机Windows amd64 / CPython3.13.2：LangGraph1.2.16，langchain-core1.6.13，完整活动依赖闭包38项，每项锁定版本及实际下载轮子SHA256。

先固定现有19个包，用pip dry-run/report解算，再下载官方PyPI轮子并按哈希从本地安装；新增27项，原19项版本无一改变，`pip check`通过。未升级整套环境、重建解释器或新增训练环境，原API依赖锁未改。不同操作系统/架构需另核对轮子，不把此锁冒称跨平台充分验证。

框架强制依赖包含langgraph-sdk、checkpoint和langsmith库；它们是已安装的代码依赖，**不表示启用云服务、checkpoint或追踪**。本项目不创建相关服务客户端；回放/微基准期间禁止网络，真实供应商适配器和`.env`未加载。

对当前环境可重复使用官方锁安装；本轮已完成安装，无需为了阅读报告再安装：

```powershell
& .\.venv\Scripts\python.exe -m pip --isolated --proxy http://127.0.0.1:7890 install --require-hashes -r requirements-langgraph.lock.txt
```

## 运行开销实测

[本地微基准](../../../evaluation/langgraph_overhead_v1.py)使用假Agent，无observer、无真实网络，两个场景各30对，路径顺序交错。每条路径预热3次，图复用已编译结构；原始逐次时间留忽略data。

|场景|原路径中位数 / p95|图路径中位数 / p95|
|---|---|---|
|无需修订|2.68 / 3.73 ms|15.99 / 19.35 ms|
|一次修订及完整重审|6.08 / 7.56 ms|22.47 / 27.62 ms|

单次首次选择路径：原路径4.95ms、图923.16ms，图值包括首次依赖导入/编译；与暖运行分开。图在这次本地测试中增加开销，不承诺更快。样本相关、机器/负载固定，不能外推真实API延迟、token费用或语义准确性；消息身份一致说明没有由适配引入新的模型提示内容。
