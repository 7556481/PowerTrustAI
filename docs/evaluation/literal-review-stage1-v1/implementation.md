# 原文审核与有据局部修订：实现与事前边界

2026-10-25；任务见 [第一阶段授权规格](../../research/literal-review-stage1-task-v1.md)。开发验证，生产不采用。实际模型效果另见收尾报告，不用本页的设计替代实测。

## 唯一候选

显式 `fact_review_contract=literal_v1` 配套启用原文审核、局部 Revision 和 `product-decision-literal-v1`。默认 `production`，真实生产仍 schema13 / JSON / product1.5。未改生产文件、生成提示、提取提示、领域语义、默认检索、知识快照和编排；固定实验后续审核关闭检索，只复用实际交付证据。生成仍用正常检索。

`LiteralVerificationOutput` 保存每个原文段落的完整审核、来源可靠性与具体可纠正缺陷，旧 `findings` 为空，绝不制造 component supported 或 fidelity faithful。段落锚点复用 `answer_anchors.anchors`，绑定回答ID、版本、全文哈希及范围。提取保留作检索/领域诊断；执行失败仍阻止认可。逐段覆盖不证明模型理解了每个量词、条件或因果。

来源选用既有 literal quote candidates，程序绑定原文范围；每个原文单元限用它实际获得的成功交付及用户提供材料，保留 delivery 身份和失败状态。固定证据接缝没有后续检索，不扩大为全库支持。原引用单独只用其绑定 Evidence；来源元数据、可靠性与正文支持分开。缺证据不等于矛盾，没有具体差异及来源纠正边界不取得修订资格。

`LiteralDefect` 要求唯一逐字定位、实际来源、差异与纠正边界，不要求审核器预写替换正文。任一成立有据发现可进入一次修订，不重建旧政策已经具备的部分可修机制；仍优先执行完整性、领域危险及高风险边界，剩余缺口不靠删除题目消失。

每项替换关联实际缺陷，声明 direct/dependent 关系及理由，只能使用关联缺陷的来源。依赖关系由模型判断，程序不制造语义证明。一次可以修前提和直接依赖结论。程序按原锚点拼装，未选正文和原分隔符原样保留；未改引用随偏移平移，跨改动引用保留未改区间，改动部分重新绑定引用。逐发现 modified/retained/unresolved 完整记账，用户显式字数限制继续校验，不采用生产默认压短。

全部不修改合法：保留原答案和版本、保存一次尝试、消耗修订轮次，终止为 review_required。真正修改则沿同一 `RunExecution` / LangGraph 重新提取及完整双审。候选报告类型保存原文结果，正常 RunStore 存读，旧版显式兼容读取；没有第二调度器、模型裁判或反思循环。

## 固定评测

28逻辑槽 = 8份新构造稿 × 两路 + 4次自然生成 + 4份自然稿 × 两路。生产路径是真实 schema13，候选仅上述贯通改动。4类错误：义务增强、明确条件错挂、必要限定取消、因果/相对影响错误及依赖结论；3份正确保护稿；1份无可据此填补的匿名容量稿。都是已见家族上的开发材料，AI辅助、用户监督，未经逐项本人确认，不是专家金标准或独立留出。

预测前只读来源复核后明确三处：新A2保留选定N-2所在稳定极限范围；新A5将维持设定点表达为运行目标，避免保证歧义；新B2参考将旧“需协调”改为“协调重要，不增强强制义务”。旧稿、旧参考及历史批不改。

参考/错误位置/保留项不进入任一路消息。两路使用相同初稿及实际交付；自然只生成一次，不筛稿、不塞错。全部计划槽保留。合法但语义差、全不修改或单链最终格式失败继续独立槽，不能因候选表现差提前删样本。

## 预算与故障

审核链每条最多新增24请求，生成每题最多2请求；分支独立扣除共享生成调用、时间和检索开销，费用仅记一次。全批最多584发送，第一发送起6小时；单链800秒、单请求8000输出token。先保存逐请求不可覆盖的预算扣额，再存实际消息身份并发送。动态纠正/重审消息不能预造哈希。模型格式纠正沿原上限；候选事实与原引用同一请求，共享至多一次格式纠正。

认证、余额、连接、限流、服务拒绝、网络超时、受理未知、冻结不符、装配/解析器程序异常、共享存储故障停止新发送。明确单链额度耗尽继续独立槽；全局额度/时间到达停止，剩余未执行。在途超时/取消采取保守共享停止。复用 `shared.batch` 和 `run_fixed`，只增加可选发送门禁和预算钩子，旧入口默认行为不改。

初次离线28槽演练发现账本复用了禁止覆盖保存器，第二次写入失败；付费前改为每请求独立记录后，28槽本地替身演练完整，另有首槽共享连接失败立即停止。沙箱内测试停滞后按项目规则使用审批和同一解释器，没有重建环境或改权限。替身只证明工程行为，所有语义得分以真实结果和独立文本复核为准。
