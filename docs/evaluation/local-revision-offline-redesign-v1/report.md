## 解决了什么

新增默认关闭的`local_revision_interface=source_actions_v2`，仅与显式literal_v1配套启用新版Revision；协议`local-revision-source-actions-v2`。原生产、旧literal_v1修订协议、事实审核/政策、生成/领域语义、Retriever和知识快照未重写。Factory清单、快照和存储保留真实版本，仍走同一Harness/图/Store。

1. **授权与意见分责。** D只来自当前版本有来源/定位/差异/纠正边界的缺陷；O逐条记录事实和领域意见。编辑选`authorization_refs`，动作选`opinion_ref`及实际`edit_indices`，不再共用finding_ids让模型猜集合。同一编辑可回应事实和领域O，领域O本身不能取得修改或来源权。短ID单射保留真实身份，context_id绑定任务、回答版本、完整业务投影；未知/错角色/跨版本均拒绝。
2. **取消伪互斥。** 编辑目标、授权D和独立dependencies共同表达关系；没有direct/dependent枚举。程序仅派生same_location/other_location，结论可同时有自身D和前提D及依赖理由。跨单元D须有依赖说明并同时改其前提；不把位置、理由或合法ID说成语义证明。
3. **正确内容来源可供给。** 支持可选集合包含关联D的正文依据及目标单元既有合法审核选择/原引用范围，避免混合段只剩纠错来源。每个D还必须实际选择至少一个自身来源。S的候选范围、模型实际选择和支持真值分开，原引用不自动支持。未选正文/分隔符和未改引用范围按原位置保留；改动区仅绑定明确选中的来源并完整重审。
4. **消息去重。** 不再整体asdict(verification/domain_review)及重复来源，改为完整问题/回答、U/D/O/S白名单投影。来源正文按实际Evidence身份只交一次，逐字范围/差异/边界与身份保留，不按字符阈值裁来源。仍有意保留短回答全文与单元文本，便于上下文理解与定位，不声称没有任何重复。
5. **一次纠正更完整。** 字段、示例、纠正说明共享合同字段表；父类型允许时一次收集额外字段、版本、授权ID、记账ID、来源和动作冲突，给准确路径及对应合法短ID集合。非法字段名限长转义且仅作数据。不清洗JSON、不换ID、不填值；原内容完整保留，一次纠正额度不增加。程序bug经过独立异常边界，不伪装为模型格式错误。

正常路径校验会使用真实冻结RevisionInput重建输出，防止只篡改派生字段或存储记录。全retained/unresolved保持完整原answer对象，计一次尝试、保留争议并终止；实际编辑才重新提取和完整双审。独立审阅发现的“无修改仍排序引用”已修复，并用反序合法旧引用验证；也补齐入口重复Evidence/审核锚点、原答案及领域版本检查。
