## 三处差异是如何发生的

下表分数统一展示为“越大越好”（FTS内置负号已翻转）；两引擎分数不作数值等价比较，仅分别解释其排序。

|674 Q10 -97|4 / 26.411840|3 / 31.157883|替代上述限值段，保留主-163不等于补回例外|

|百万 Q12 3124981|4 / 30.943075|3 / 32.767288|污染招标材料替换，不能用共同不足掩盖新增下降|

Q10完整47条匹配集合相同，必要段就在第4，不是漏建、读错源或query语义导致不匹配。Q4两路精确命中562091、Q12两路30099；已知必要/替代片段在两路均匹配，Top256集合不同，但没有遍历全体，故全匹配集合逐项等同仍未知。相同总数不作集合相等证明。

48项词DF跨引擎核对无差异；12个相关文档的词频由原预分词输入取得，精确长度由FTS docsize取得，平均长度由FTS averages记录取得，T用Query.explain直接给出idf/freq/dl/avgdl。只读取固定词项及固定ID，不扫描整个词表或建设统计库。DF读取674约0.033秒，百万Q4约2.710秒、Q12约1.061秒；独立精确计数另计，不混入Top-K性能。

两路k1=1.2、b=.75一致。FTS的IDF是log((N-df+.5)/(df+.5))，非正值夹至1e-6；T是log(1+(N-df+.5)/(df+.5))。T长度是量化值：如-97的193→184，Q4新闻162→152，Q12招标303→280。使用这些实测统计复算，FTS12分数误差<1e-8，T误差<.0002（浮点/avgdl精度边界），足以解释相关名次变化。算法定义参见[SQLite官方BM25文档](https://www.sqlite.org/fts5.html#the_bm25_function)；T公式和当前0.27.0/native format7取自实际explain，不用未确认的其他版本文档代替。

反事实只用于诊断，不是第二个排序候选：Q10若仅换IDF，-97为30.682598仍小于-206的31.045055；仅换长度也未超越；两者合并31.157880才超越。这一对是两因素共同翻转。Q4仅IDF替换已使新闻44.579836超过背景43.818199；Q12仅IDF替换亦使招标31.864546超过原段31.764197，长度量化进一步放大。匹配词/词频及完整复算见[评分证据](score-attribution.json)，包括Q10的voltage、voltages、contingency、if，Q4的nerc/cip/to与组织等词，Q12的年份及指定/强制/定位等词，不能用词面命中当语义充分。

这些边界分数并不相等，故不是同分规则造成这三处截断。FTS明确score/rowid升序；当前T没有显式rowid第二排序，原生同分内部规则未单独确认，不能承诺任意32边界稳定。没有把所有排序变化都归为一个引擎缺陷。

## 唯一保护机制与质量复核

唯一候选是**Tantivy原评分召回最多32，再用同一规模原SQLite FTS5 BM25按score/rowid选3**。它保留原query AST、全局统计语料和最终证据预算；无文档ID/词语特判，无模型、去重、无限过取或邻接扩张。仅在evaluation的实际T适配器子类中实现，生产Factory/配置没有入口默认启用。

参考FTS文件SHA和成员数在启动核对，查询前后stamp核对；SQL只对32个候选交付分数，但内置bm25仍依赖全局词项统计，不能称O(32)或没有全库成本。SQL计划为:=M1和临时排序；内部成本未逐条C函数剖析，不能把全部复排耗时精确归因到DF。取证本身仍只向原来源层请求最终3条及原邻接，原生超时/取消/身份门禁和释放策略保留，复排亦有30秒总限时与SQLite取消检查，没有SQLite失败回退。

96组逐题/逐轮比较中，候选最终root与完整neighbors的正文、版本、provenance均与FTS逐对象相同，预算全部符合。674 Q10的1.05pu和TO额定例外三轮均恢复；当前T三轮均缺失。Q4/Q12原有相对较好片段均恢复，迁移4题也没有候选新增交付差异。这是对已知损失的通用程序修复证据，不是有限32与全库原排名严格等价证明，更不证明原FTS答案正确。

正文复核为AI辅助、用户监督的开发复核，非专家金标准：Q4共同网络安全内容仍不足以充分回答TO/DP问题，Q12三段仍不能支持虚构未来/现场数值；Q2的418888与1721786近重复仍占2/3，候选照旧保留，不能宣称多样性改善。Q10百万行业样本不含负ID文献，不能在那里伪造-206自然召回，必要限值验证依赖独立674集。本批没有看到候选独有关键覆盖退化，但材料有限，不做全语料无损保证。
