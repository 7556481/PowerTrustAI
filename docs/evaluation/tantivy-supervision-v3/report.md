## 监督语义

绝对deadline持久化，四小时包括暂停、休眠及观测空窗，不重置；每个监督实例的monotonic elapsed用于分段耗时诊断。电脑不能采样时不要求继续采样；恢复后先判绝对期限，过期不准入或继续馈送。长间隔记录observation_gap/unobserved_resources，不补写资源正常。

独立监督进程记录自身及子树内存、PID与创建时间、心跳、可用内存、文件量及服务busy。停止请求先落盘；正常清理宽限30秒，仍不退出只终止已登记且创建时间匹配的隔离子树，监督本身计入内存但不入终止白名单。监督重启发现旧阶段活进程时保守置无效、请求停止并按同样宽限处置，不盲目接着进入下一阶段。失败目录标记INVALID，计划文件存在则拒绝再启动一次。

writer封装只拥有一次原生close/merge等待；过期或异常进入清理，已成功commit且没有后续馈送则不重复commit。原构建器先保存primary-failure，再清理；清理异常独立记录，不替换主异常。输入准备/启动/馈送/commit/merge/验收/计时都检查准入，结束时再次检查期限。原v2正常建库循环及分词/评分不变，仅修错误归档接线。
