## 逐项统计需求

|统计|精确含义|可在建库时保存|查询时仍需取得|
|---|---|---|---|
|N|同一索引语料全部文档数|是，更新索引时同步|身份核对后常量读取|
|avgdl|所有文档同字段精确token数之和/N|是；不是T量化长度的平均|常量读取|
|dl|每个候选的精确索引字段长度，包含原标题增强|是，每ID一行；不能用T量化fieldnorm替代|最多32项读取|
|tf|查询短语在候选中的实际出现次数，重复/重叠须按原位置语义|可保存词项位置序列；单词Counter只支持单词，不足以处理短语|对至多32候选计算各查询短语次数，不能简单拆词相加|
|DF|包含整个查询短语的文档数，而非单词DF、总出现次数或仅候选内DF|单词DF可保存/读现有T词典；固定短语可预存但任意长度短语无法靠有限词表预存保证|首次任意短语须取得全语料精确DF，且保留查询中重复短语及Boolean语义|

现有Python标准sqlite3没有FTS5 xInst/xQueryPhrase自定义辅助函数入口；当前T Searcher.doc_freq接口只接单词，不能把phrase字符串当作等价词项。位置索引可以计算任意短语DF，但其精确全语料计数不受32候选约束。需要独立解决此依赖，不能用同候选内tf或min(word_df)代替。旧单词评分复算证据不自动覆盖短语/NOT/嵌套Boolean。
