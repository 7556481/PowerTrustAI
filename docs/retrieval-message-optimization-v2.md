## 已实施

检索候选 `topic_v5_grammar_v1`，查询处理 `topic-subject-grammar-bm25-v2`：在v4主体约束下仅移除明确的单字语法词，如时/会/使；单位、数值、负载状态、方向及否定词不进入删除集。主体别名继续保留在完整正向OR，匹配成员仍由同一主体OR限定；BM25计分词项改变，所以分数/顺序/最终Top-K可能变化，不能称排名等价。维持score,rowid稳定排序、K、正文/邻接与精确身份校验。已有每run有界数字缓存没有扩大，未用命中证明首次收益。

审核候选 `lossless_v1` / v9.20：重复输入值通过共享表准确提供一次，作用域与可选ID不合并，所有必要正文、字段、元数据均在同一请求中。离线expand逐字恢复原结构；原输出协议及严格校验不变，不替换ID或修补JSON。小消息若共享包装加说明反而更大，保留原包装，仅去JSON排版空格与加明确嵌套说明。

具体非法JSON根因：上一轮响应正常stop、6669字符，有完整结尾，却在位置2836关闭数组时尚有组件对象未闭合。新共同纠正诊断只记录标点位置与期望闭合符，不抄正文；提示分别说明findings和原引用的对象/数组嵌套，防止将两种结构混用。JSON-only已在适配器启用，不冒称首次新增；非法JSON继续严格拒绝，保留一次纠正与完整失败记录。

未采用：所有中文单字广泛删除（状态/限定丢失风险）；设备主体优先（R1虽约1.07秒、匝数/饱和字面命中增加，却丢正弦并带入商品广告；R6偏目录，关键字不是证据）。这些失败留在本机小型实验记录，没有索引/大库副本。
