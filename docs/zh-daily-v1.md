## 日常入口

本机双击根目录 `start-powertrustai.cmd`，或执行：

```powershell
Set-Location D:\PowerTrustAI
& .\.venv\Scripts\python.exe -m backend --open --port 8765
```

已有同版本、同模式服务会复用，不重复启动。日常网址是 `http://127.0.0.1:8765/`。启动终端 Ctrl+C 正常停止，或在空闲时执行 `& .\.venv\Scripts\python.exe -m backend --stop --port 8765`；有活动或排队任务时拒绝远程停机。真实模式只由服务端既有入口加载 `.env`，不交给浏览器。演示用 `--demo --open`，不要与同端口真实服务混用。普通公开克隆不含本机知识库或模型凭据。

固定访问令牌仍在 `data/runtime_local/access-token`，存在即复用。已鉴权的本机启动器生成60秒单次票据，OS普通浏览器通过本地引导文件POST兑换HttpOnly、SameSite=Strict会话，长期令牌不进URL或页面。会话七天有效，服务端仅保存摘要与到期时间；正常重启可继续使用。高级手动连接和“忘记连接”保留。旧主动保存的令牌在成功认证后迁移为会话并删除旧保存项，避免两套长期身份叠加。其他API保持访问鉴权与同源保护；跨源null只允许一次性票据兑换。

本机一次性引导文件和会话登记文件属于私有运行资料，不归档或发布。单用户localhost方案不是多租户认证；同机恶意程序、浏览器站点数据被清除或会话过期仍需重新通过启动器连接。

## 实现与连接诊断

- `backend/launcher.py`、`local_session.py`、`__main__.py`、`api.py`：启动、复用、会话、注销、空闲正常停机。现有ApplicationService与Harness继续负责运行。
- `backend/config.py`：可选私有 `daily-knowledge-v1` 配置选择实际固定快照，环境变量优先，演示不加载它；索引必须在项目data内。原默认快照用于历史复现。
- `model_adapter/deepseek.py`、`runtime.py`：连接TLS/发送/接收/读取阶段，仅保留异常类型、errno、winerror。没有记录异常文本、密钥或头，不把Git代理套到模型API，不关闭SSL。
- `agents/generation.py`：版本化中文、直接回答、简洁提示，不后置翻译或程序截断；`services/claim_obligations.py`、`claim_extractor.py`：日常类别协议提示明确，仍严格解析，不放宽非法类型。
- `services/generation_query.py`：中英文混合快照仍保留原查询空命中后的有限英文补检；原BM25与排名参数不变。
- 前端：答案、简短处置、实际引用优先；辅助输入和详情默认折叠，历史分页、长列表限高、长词换行。Evidence全文、版本、NLI、反馈仍可回查。

旧7d0运行只有查询转换失败，缺失底层异常，不能认定不支持中文。本轮不带凭据的网络探测在受限执行环境出现PermissionError/WinError10013；正常宿主网络TLS成功并得到预期未认证401。随后真实请求成功。该差异提示本机执行环境限制，但不足以断言旧失败的唯一原因。Git网络另行核验。
