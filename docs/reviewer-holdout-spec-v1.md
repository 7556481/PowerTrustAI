2026-10-20。整体建设规则已获会话接受；本次补充调用上界、错误支持分母及训练污染限制。不代表最终评测协议或保留样本已冻结。允许少量来源选择与谱系核对，暂不出题/预测，不修改生产审核。

| 项目 | 建设约定 |
|---|---|
| 评测对象 | 评审组件：输入问题、要求、题设前提、文献证据及待评回答，输出完整性和支持性。不评价检索、生成或整个RAG系统 |
| 开发边界 | CT/TR/SW/RC全部已见家族、相关来源、近似题和变体留开发组；SW-002互补候选也不能进入保留组。见[分组清单](reviewer-holdout-source-groups-v1.md) |
| 保留分组 | 按原始文档及来源谱系分组。同文档不同页、转载、镜像、翻译和近重复不拆两边；改URL、文件名或SHA不自动成为新来源。谱系不明先hold |
| 题型覆盖 | 完整、遗漏、无据附加、明确矛盾、错误映射/规则连接、合理同义表达；不强制每题具有全部变体。同一家族变体不是独立题 |
| 标签确认 | AI建议、本人结合完整原文确认，保留依据、范围、允许表达及确认记录。歧义先hold，预测前解决或排除；不称专家金标准，不把AI复核替代本人确认 |
| 预测隔离 | 出题和标注人员可以阅读保留资料；独立性指相对开发过程隔离，不是无人看过。预期、参考答案、变体角色和错误位置不进入模型消息 |
| 协议冻结 | 预测前绑定模型ID/参数、提示、解析器与源码、证据快照/定位/范围、问题/前提、评分要求/参考判断单元、纠正/停止规则、指标及计划样本清单的版本与哈希。v4只是现有候选，尚未指定为保留集最终协议 |
| 执行冻结 | 计划请求清单及每项有限纠正次数共同推导调用上界，不另加任意付费总帽；保留超时、共享/执行故障停止、无自动重发及有限执行授权；失败样本不替换或追加到通过 |
| 全量报告 | 所有计划样本逐项交代有效完成、契约/连接/存储等失败、停止后未执行或事前hold；完整性、支持性及错误支持分开，不合并综合准确率 |

**指标口径草案：** 事前hold不进入计划批次，但保留排除理由；预测后失败不能转hold以移出分母。执行完成记录为严格解析通过样本数/全部计划样本数，同时列各失败和未执行数。完整性按预先固定的每个要求报告参考状态与预测状态的计数/混淆表，另列整体完整性；同步给出有效要求数与全部计划要求数，不隐去失败对应要求。

支持性以预测前确认的参考判断单元为统计单位，允许合理同义、拆分或合并表达的匹配；不能拿模型自行拆出的判断数量当分母。语义匹配办法及人工复核流程须在批次前确定，复核只记录匹配/分歧，不按结果改原标签。遗漏、无法对齐、部分覆盖或同一参考单元出现冲突预测另列，不能静默挑一个有利标签。报告参考/预测支持标签计数。令F为可对齐单元中参考为证据不足、明确矛盾或不可评估而预测为支持的数量，A_NS为可对齐的非支持参考单元数，A_SP为可对齐的全部支持预测数；同时报告**F/A_NS**与**F/A_SP**，均附原始分子分母，分母为0时记N/A而非0%。按预先冻结的参考单元对齐，同一单元不因模型拆出多项而重复计数；冲突或无法判定匹配另列，不挑有利标签。另列无法对齐、契约失败、停止后未执行的参考单元数，并给出全部计划参考单元数，不只展示有效结果。执行失败不产生有效语义预测，也不记为语义正确。

**结果使用边界：** 查看结果只作既定评估和错误归档，不据此调协议、标签或样本。若查看该批结果并据此修改协议，该批对后续版本转为开发材料；原冻结身份、原成绩和失败记录保留。下一版本须另建未参与该修改的新保留组，不能反复测试后继续称独立验收。单纯查看/报告不自动等于调参，但再次执行不属于本规格自动授权。

**调用上界：** 对计划中的每个初始请求i固定最大纠正次数c_i，调用上界为Σ_i(1+c_i)。每样本如含多个计划请求，逐请求列清，不把样本数冒充请求数；共享故障/超时/存储等停止可使实际调用低于该值。不得用新增任意付费总帽截断既定计划，也不以此解除单请求限制或允许无限纠正/自动重发。

**独立性限制：** 来源隔离只约束资料未用于本项目既有调试及结果后调整，不能证明基础模型预训练或其他训练未见过公开资料；训练污染状态未知，不作训练未见或绝对无泄漏声明。

**当前待填：** 来源候选及谱系由本人后续复核；模型具体参数、最终提示/解析器、题型配额与样本量、参考单元匹配细则、纠正及停止数值均在选资料和正式批次前另行填实并冻结。本规格不是付费许可，不启动预测、LangGraph迁移或生产改动。四家族历史见[开发汇总](evidence-bound-development-summary-v2.md)。
