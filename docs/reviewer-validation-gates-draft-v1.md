## 先确认规格，再确定样本与执行

1. 本人先决定上表能力、关键错误清单、数值门槛及本阶段可接受结论：建议定位为“有限来源隔离组件验证”，不作生产准入或总体稳定率证明。
2. 样本规模须在选来源之前依据目标结论确定：以独立来源谱系/问题家族为规划单位，不把一题多个单元当独立样本。每个目标支持类别和边界都需事前规定最低覆盖；未覆盖能力标未验证。当前不随意冻结N或为省调用把极小样本包装成全面验收。
3. 能力与规模确认后才开展来源筛选。CT/TR/SW/RC、MIT/BIPM、EIA/NRC及相关同文档/转载/翻译/近重复均排除为新保留来源；有限谱系检查不证明基础模型未见。若来源迫使修改协议，先转开发，保留原记录，再重立边界。
4. 新题的要求、假定、语义单元、支持参考、类型、歧义hold及标签映射须预测前由本人逐项确认，记录AI辅助用户监督身份。原标签名不自动转换；unknown不当不相关。参考和质量预期不进模型消息。
5. 先独立冻结下一阶段协议身份：v7可作为候选，但旧通用协议v1绑定v5，不能将其称为已经绑定v7的可执行协议。另版清单须明确继承及差异，并绑定当前v7提示、v6解析、覆盖/支持定义、类型、对齐及双分母精确定义，不覆盖旧冻结。
6. 最终批次再冻结资料/任务/代码/消息SHA、完整顺序及选序方法、模型/服务/参数、N、最多2N调用、每项最多一次格式纠正、超时、预算准入期限、首失败停止与attempt锁。复用现有控制器，不另建调度器；无传输重试、不自动恢复或换目录补跑。随后另获具体目的地、载荷和费用授权；旧授权不沿用。

## 判定与报告

执行、覆盖、支持、类型、理由分别验收，不合并综合准确率。错误支持F/A_NS及F/A_SP必须沿新批事前定义明确分母资格、对齐限制与零分母N/A，不能用旧批名称替代新冻结的精确定义。计划/尝试/有效/失败/未执行按来源、题型分别报告，另列未对齐及冲突；执行失败、证据不足、工程前提缺失和语义疑点分开。

未达任一拟采纳门槛则该能力不通过，或因样本/类别覆盖不足记未验证；保留原预测、参考与匹配规则，不补跑到通过。若依据结果开发，该来源转开发材料，原冻结成绩不改。对齐与正确性、依据ID与支持成立、程序composition与语义拆分、组件通过与工程安全认证始终分开。

本草案确认后也只授权继续准备相应规格；选来源、题卡确认和实际付费执行仍分别按后续明确范围推进。
